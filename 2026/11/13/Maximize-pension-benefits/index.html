Overview

近期母上大人针对养老这一 affair 突然发问，吾从未有相关的知识储备，有的话也仅仅停留在表面现象。

据母上所述，可一次性补缴10w，后面就能每月拿多少k这样子。

这本质上和投资一样了，区别在于投资可以选择随时抽身离场（说的好像真的一样hhh），但养老不行，投的钱会一直被锁定到退休后才能分月领取。

因此，如何规划养老使得收益最大化的确是一门学问。

养老金组成及发放

根据国务院关于建立统一的城乡居民基本养老保险制度的意见（国发〔2014〕8号）（以下简称意见）所述，养老金来源主要由以下三部分组成：

  • 个人缴费：即参保人每年根据当地不同的缴费档次缴纳的保险费用
  • 集体补助：即由社会其他经济组织或个人（例如父母的子女）根据最高缴费档次自愿补助其他参保人
  • 政府补贴：即由政府根据标准全额或成比例地补贴参保人

落到具体的人上，一般就是自己缴的 + 子女资助的 + 政府给的就是个人账户里实际存在的钱了。

知道怎么交了，怎么领呢？

A: 满 60 周岁，累计缴费满 15 年即可领取。

知道怎么领了，我每个月领多少？

A: 意见中提到，最后参保人享受的养老金待遇由两部分构成：

  • 基础养老金：这部分由政府直接发放，根据具体情况，适当调整，中央仅确定最低标准，实际发放需要由当地政府自己定
  • 个人账户养老金：根据动态调整的计发系数及账户余额决定每个月能领多少钱

具体来说，每个月领的钱就是基础养老金 + 个人账户余额 / 计发系数。

需要注意的是，最终享受的养老金待遇是支付终身的，什么意思？

A: 简单来说，就是即使你个人账户里面钱领完了，但只要你还活着，政府照样发给你和之前一样多的钱。

OKay，理论和依据说完了，我们来看一个具体的例子，做做简单的算术题。

以上例子没有考虑到计发系数调整、基础养老金调整及其他激励型政策的影响，仅供参考。

再回到母上大人提到的一次性补缴10w的情景，最终可以领取的养老金变为：(100000 + 10620 + (800 + 85 + 5000) * 9 ) / 139 + 368 = 1544 CNY

确实上千了，但是补缴不会允许存在这么高的档次，根据城乡居民基本养老保险补缴政策所述，“同一个缴费年度内个人缴费总额不得超过当前年度最高缴费档次标准”，而最高缴费档次一般是 5000 CNY。

NOTE:

  • 一次性补缴主要是给了凑够年限的选项，并不是交齐之后，后面就不用缴了
  • 激励原则上是“长缴多得、多缴多得”
